## 保留的风险（不阻塞）

- 旧 pipeline 被新 `start` 取消后，若正卡在 `preview_route`/`audit_run`，仍可能与新 pipeline 并发调用 bridge；generation 只阻止写状态，不阻止工具调用。窗口很短，暂不引入工具级取消。
- `confirm()` 只保证不提交、不写回执；最终提交仍由跑步页用户点击。
- trace 文件不自动清理。
- Agent 的 `preview_route` 使用默认 `days_ago=0`，若当天时间窗已过会报错并显示中文原因。
