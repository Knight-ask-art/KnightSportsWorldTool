好想跑 v0.1.7

本次更新（v0.1.7）：
  修复画线时点位反复加载失败：不再按每 10 m 目标距离重拉点位。
  自动刷新最多 1 次 / 5 分钟；10603 冷却按账号隔离，A 账号不再锁住 B 账号。
  点位读取失败时保留上次加载的点位，不再清空地图和检查表。
  提交复用地图上显示的那套点位，不再重新随机抽一组。
  10603 时允许复用同账号 / 跑区 24 小时内的缓存点位，并标注来源距离。
  后台刷新不再重置地图视野；点位限流时显示冷却倒计时与真实原因。
  会话 token 改为 DPAPI 封存（token_enc），旧明文启动时自动迁移。
  单实例保护：第二个窗口会聚焦已有窗口并退出，避免互相覆盖 data/。
  自动更新要求 zip 和安装包都带 sha256，且只接受 https（localhost 除外）。
  手动选择的跑区按账号保存，下次登录 / 重启自动恢复；下拉框可切回「自动」。
  围栏读取异常时停止提交，不再跳过区域校验。
  提交页常驻结果卡：结果未知时锁定提交，直到完成只读回执核对。
  检查表行可点击跳转；没有修复入口的提醒不再显示成按钮。
  路线撤销改为 50 个快照栈，支持 Ctrl+Z / Ctrl+Shift+Z。
  控制点悬停显示序号，可选中、Delete 删除、拖动微调。
  点位冷却期间刷新按钮置灰，并每秒更新「冷却 Ns」。
  实测：点位接口每次随机返回 5 个点（池子至少 7 个），距离只影响候选范围。

启动：
  双击「好想跑.exe」。
  请保持 exe 与依赖文件夹在同一目录，不要只移动 exe。

首次启动：
  会显示登录页，登录你自己的运动世界账号后进入工作台。
  首次会自动显示 5 步新手引导；之后可在「设置 → 关于 → 新手引导」重新打开。
  `data` 文件夹会在首次启动后自动生成，里面是本机会话、缓存和回执。
  密码不会写入磁盘；token 只保存在本机 data 目录。

路线：
  推荐「手绘」：点地图加点，右键删点；需要绕圈时再打开「闭合」。
  闭合默认关闭；导入 GPX/GeoJSON/CSV 也默认保持开放，不会自动首尾相连。
  「自动」功能仍在开发中，不建议使用；可改用导入或田径场。
  围栏校验会检查整段路线，提交前留意「越界 0 点 / 0 段」。

海拔：
  参数页的「海拔来源」支持 自动 / 固定 / 区间 / 模板。
  自动：以基准海拔为中心轻微波动，像真实气压计。
  固定：全程固定，爬升为 0。
  区间：按最低–最高海拔合成坡形；基准海拔不参与。
  模板：读取本机 GPX/JSON 海拔，只在本机解析，不会上传；区间可留空。
  基准海拔只在自动/固定模式使用；区间/模板模式会灰掉，避免混淆。

记录与调试：
  「记录」页可查看轨迹、爬升、分段和平台检查项。
  源码/命令行调试：
    python -m replica.adapters.cli --version
    python -m replica.adapters.cli --token <TOKEN> --uid <UID> --record-json <RRID>
  原始详情 JSON 只输出到 stdout，日志走 stderr。

更新：
  「设置 → 关于 → 检查更新」读取 latest.json，安装版与便携版各自升级。
  下载有进度条，可暂停续传或取消；下载或校验失败时保留当前版本，不覆盖程序目录。
  data 目录（登录状态、回执、限额、设备指纹）任何形态升级都不会动。
  回滚是手动的：下载 latest.json 里 rollback 指向的旧包覆盖即可。

退出：
  在「账号」页点「退出登录」会回到登录页。

注意：
  首次登录可能需要 5–15 秒（本地解极验）。
  10121 表示账号还在手机端登录，请先在手机上退出。
  不要同时运行旧版本和新版本：回执/限额各存一份，会失去跨版本防重保护。
